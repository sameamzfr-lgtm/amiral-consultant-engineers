# Amiral Consultant Engineers — Horizontal Portfolio Website

Open `index.html` in your browser. Upload the complete directory to your web host, preserving `assets/`.

## Design
Inspired by the supplied business cards: orange `#F27501`, charcoal `#373435`, black and white; angled corner accents; animated left-to-bottom edge gradient.

## Interaction
Desktop: vertically scroll through the portfolio section to slide horizontally through 20 project cards. Arrow buttons step between cards, and category pills filter project sectors. Mobile: naturally swipe cards horizontally. Reduced-motion preferences disable decorative animation.

## Content integrity
The project cards describe leadership's employment-era projects, **not Amiral-contracted projects**. Project imagery was supplied in the earlier email-derived portfolio and is labeled illustrative; verify project details and permissions before publication.

## Deployment
The supplied separate `index.html` referenced missing CSS/JS/assets. This package is self-contained with those files included. No backend is required. Contact action opens an email draft.
